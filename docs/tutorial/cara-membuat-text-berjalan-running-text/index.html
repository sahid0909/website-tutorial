CARA MEMBUAT TEXT BERJALAN ( RUNNING TEXT)

2026 M08 23

1. Teks Berjalan Dasar (Ke Kiri)Ini adalah bentuk paling standar dari teks berjalan. HTML <marquee>Ini adalah contoh tulisan berjalan dasar</marquee> 2. Mengubah Arah TeksAnda bisa mengatur arah gerakan teks menggunakan atribut direction.Ke kanan: <marquee direction="right">Teks berjalan ke kanan</marquee>Ke kiri: <marquee direction="left">Teks berjalan ke kiri</marquee>3. Mengatur Kecepatan TeksGunakan atribut scrollamount untuk membuat teks berjalan lebih cepat atau lebih lambat. Semakin besar angkanya, semakin cepat gerakan teksnya. HTML <marquee scrollamount="5">Berjalan lambat</marquee> <marquee scrollamount="15">Berjalan cepat</marquee> 4. Mengatur Lebar Teks BerjalanAnda bisa membatasi area kotak teks berjalan agar tidak memakan seluruh layar. HTML <marquee width="50%">Teks ini hanya berjalan di setengah layar</marquee> 5. Memantulkan Teks (Bounce)Jika Anda ingin teks bergerak dari satu sisi ke sisi lain lalu memantul seperti bola, gunakan atribut behavior="alternate" HTML <marquee behavior="alternate">Teks ini akan memantul</marquee>
