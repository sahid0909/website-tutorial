Membuat formulir (form) admin berbasis web menggunakan HTML

2026 M08 25

1. Siapkan Struktur Dasar HTML

HTML
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Halaman Admin</title>
</head>
<body>

    <!-- Kode Form Admin akan diletakkan di sini -->

</body>
</html>

2. Tambahkan Tag <form>

HTML
<h2>Form Login Admin</h2>
<form action="proses-login.php" method="POST">
    <!-- Isi form ada di sini -->
</form>

action: Tempat tujuan data akan dikirim saat tombol dikirim (submit).
method: Cara data dikirim, biasanya menggunakan POST untuk data rahasia seperti kata sandi (password).

3. Tambahkan Input dan Tombol

HTML
<h2>Form Login Admin</h2>
<form action="proses-login.php" method="POST">
    <label for="username">Username:</label><br>
    <input type="text" id="username" name="username" placeholder="Masukkan username" required><br><br>

    <label for="password">Password:</label><br>
    <input type="password" id="password" name="password" placeholder="Masukkan password" required><br><br>

    <button type="submit">Masuk</button>
</form>

<label>: Teks penjelasan untuk kolom isian.
input: Kolom tempat pengguna mengetik teks.
placeholder: Teks petunjuk samar di dalam kolom isian.
required: Aturan agar form wajib diisi sebelum dikirim
