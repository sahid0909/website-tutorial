Cara reset Epson L3110

2026 M08 21

Cara reset Epson L3110 yang selanjutnya adalah dengan menggunakan aplikasi resetter Epson. Untuk cara ini, pastikan kalian sudah download dan instal aplikasi resetter Epson di internet sebelum mencoba beberapa langkah caranya berikut ini. 1. Hidupkan printer Epson L3110 kalian 2. Buka aplikasi resetter kalian, lalu di opsi Select, pilih seri L3110 3. Di tampilan awal, pilih opsi Particular adjustment mode, lalu cari opsi Maintenance 4. Klik opsi Waste ink pad counter, lalu klik OK 5. Di tampilan berikutnya, kalian perlu mencentang kolom Main pad counter, lalu klik opsi Check 6. Kembali centang kolom Main pad counter dan klik opsi Initialize 7. Tunggu hingga proses selesai, lalu restart printer Epson kalian. Itu dia cara reset Epson L3110 secara manual atau dengan resetter yang pasti mudah dan tidak akan memakan waktu banyak!
